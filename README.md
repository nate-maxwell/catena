# Catena

Catena is a node-based texture generation application built around graph-driven
image workflows, Qt tooling, and array-first texture processing with `numpy`,
`opencv-python`, and `scipy`.

Plugin support is built in. Plugins can register nodes, add shelf buttons and
menu actions, define dockable panes, and persist their own settings through the
public API documented in [catena/api/README.md](catena/api/README.md).

Extremely work-in-progress
